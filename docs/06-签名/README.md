# 签名

## 规则

| 项 | 说明 |
|---|---|
| 需要什么 | `sign/release/private.pem` + `sign/release/certificate.pem`（或华为快应用 IDE 生成的等价签名配置） |
| 放哪里 | **uni-app 工程根目录的 `sign/`**（不是本仓库）。华为快应用 IDE 也可直接导入/生成 |
| 生成方式 | 华为快应用 IDE 生成或导入证书；也可用华为官方工具链生成 |
| `.rpk` 校验 | `.rpk` 本质是 zip，签名信息在 **`META-INF/CERT`** 条目 |

## 三条硬规矩

1. 🔴 **密钥绝不入库**。本仓库 `.gitignore` 已排除 `sign/`、`*.p12`、`*.pem`、`*.p7b`、`*.cer`、`*.csr`。证书/私钥由持有方单独安全交付。
2. 🔴 **验广告必须用 release 签名的包**。工具链内置的 **debug 签名**会被鲸鸿动能判 **`1004 media is not exist`**（服务端按「包名 + 签名指纹」查媒体，查不到）。
3. ⚠️ `--disable-sign` / `nosign` 包**只能验证构建链路，不能上架**。

## 为什么签名与媒体绑定

鲸鸿动能后台创建**媒体**时登记的指纹就是 release 签名指纹；服务端按「包名 + 签名」查媒体。
所以：**换签名 = 换媒体**，需要同步更新后台登记，否则 `1004`。

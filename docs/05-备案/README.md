# 快应用 ICP 备案

## 结论

**需要新增备案，但不是"重新备案主体"。**

网站 / App / 小程序 / 快应用**共用同一套服务信息备案序列，各自显示不同后缀**：

| 形态 | 备案号后缀 |
|---|---|
| 网站 | `-1` |
| App（Android APK） | `-2A` |
| 小程序 | `-3X` |
| **快应用** | **`-4K`** |

## 办理路径（华为 AGC「APP 核准(备案)指引」原文四情形）

> **2.4 快应用/快游戏核准(备案)**
> 快应用/快游戏需要在**华为云核准(备案)系统**进行核准(备案)。
> 1、主体信息和快应用信息均未在任何接入商备案 → **首次备案**
> 2、**主体信息已备案，但快应用信息未在任何接入商备案 → 新增互联网信息流程**
> 3、主体和快应用信息已在其它接入商备案，未在华为云备案 → 新增接入流程

工蜂属**情形 2（新增互联网信息）**——不需重做主体核验，工作量比首次备案小。

> 另有「快应用官网（quickapp.cn）」备案系统，华为/魅族/联想/努比亚/荣耀等平台的快应用均可备案。**本项目走华为云**，与 AGC 上架校验链路一致。

## 待填写的备案要素

| 项 | 值 |
|---|---|
| 备案类型 | 新增互联网信息服务 |
| 接入商 | 华为云 |
| **资源类型** | **备案授权码**（域名不在华为云） |
| 备案授权码 | ⏳ 待获取 —— 由 ECS / Flexus **包月 ≥3 个月**生成；一台服务器最多 **5** 个；**1 个只能备案 1 个互联网信息** |
| 应用名称 | 工蜂 |
| **快应用包名** | `com.genfee.quickapp` 🔴 **已定死，不可改** |
| **APPID** | ⏳ 待 AGC 创建快应用后获取；⚠️ **备案时填的 APPID 必须与上架时的 APPID 一致** |
| 主体信息 | ⏳ 待确认华为云账号下的主体备案状态（决定走"新增互联网信息"还是"首次备案"） |

## 硬约束（踩过才知道）

| # | 约束 |
|---|---|
| 1 | 🔴 **华为云的备案号与包名一一对应**（官方原文：「华为云的备案号与包名只能是**一一对应**的，需要分别申请」）→ 包名提备案后**不可改** |
| 2 | 🔴 **备案时填的 APPID 必须与上架时的 APPID 一致** |
| 3 | 🔴 **未备案不得上架**；AGC 上架环节会做备案校验 |
| 4 | 🔴 **备案号须在应用显著位置展示**，并在下方链接备案系统网址；未标识 → 上架不通过 / 已上架被下架 |
| 5 | ⚠️ 上架后 **30 日内**还需完成**公安联网备案**（`beian.gov.cn`） |
| 6 | ℹ️ 一个华为云账号只能备案一个主体 |

## 工期

| 阶段 | 耗时 |
|---|---|
| 华为云初审 | 3–5 个工作日（驳回需重排队） |
| 工信部短信核验 | 通过初审后 **24 小时内**必须完成 |
| 管局审核 | 2–20 个工作日（各省差异大） |
| **合计** | **约 5–25 个工作日** |

⇒ **这是全线最长工期项，必须第一天就启动**（只要包名 + 授权码齐了就能提交）。

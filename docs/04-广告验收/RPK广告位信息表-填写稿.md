## 子表③ 快应用自检项

逐条填「是否满足」。**未接入的形式填「不涉及」**（本项目原生/Banner 填不涉及）。

| 类型 | 自检条目 | 工蜂填 |
|---|---|---|
| 通用 | 调用广告请求前必须展示用户隐私协议 | 满足 —— 启动时弹隐私政策同意框，未同意不创建广告实例、不发请求 |
| 通用 | 只允许广告区域可点击跳转落地页 | 不涉及（一期无原生广告）／插屏与激励视频为平台自渲染 |
| 通用 | 请求失败禁止频繁重试（只能重试 1 次） | 满足 —— 失败即提示，不自动重试 |
| 通用 | 禁止设置定时器循环请求广告 | 满足 —— 定时器仅用于按钮倒计时文案 |
| 通用 | 一次请求的广告不能重复展示 | 满足 —— 展示后销毁实例并重新创建 |
| 通用 | 实时请求展示；预缓存注意 1 小时有效窗口 | 满足 |
| 激励视频 | 无广告返回时不显示入口或给合理文案 | 满足 —— 恢复按钮文案并提示「广告加载失败，请稍后重试」 |
| 激励视频 | 广告入口防止快速点击触发多次展示 | 满足 —— `adLoading` 状态位拦截 |
| 原生 ×4 | （素材/上报/关闭按钮/startDownload） | **不涉及**（一期未接入原生广告） |
